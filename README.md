# Тренировки

Мобильное одностраничное приложение для программы тренировок и записи весов и повторов. Разделы питания, веса тела, фотографий и заметок убраны из интерфейса; их старые данные сохраняются в приватном бэкапе.

## Запуск на новом ноутбуке

Нужны Docker Desktop и Git. Проект и данные находятся в приватном GitHub-репозитории; публичный Docker-образ данных не содержит.

```bash
git clone git@github.com:vsfomin/fitness.git
cd fitness
docker compose up -d --build app
```

Открыть локально: `http://127.0.0.1:18080`. Все записи из `data/db` подхватываются автоматически. Папка `data` подключена к контейнеру напрямую, поэтому новые записи сразу остаются на ноутбуке и попадают в следующую облачную синхронизацию.

На основном Mac Docker Desktop запускается после входа в macOS через LaunchAgent `~/Library/LaunchAgents/com.fomik2.fitness.docker.plist`. Политика `restart: unless-stopped` в `compose.yml` автоматически восстанавливает контейнер приложения после запуска Docker. До полноценной перезагрузки macOS требуется вход в пользовательскую сессию.

## Доступ с телефона

Постоянный HTTPS-адрес: **https://rosy-river-0106.a.tuna.free**. Открыть его в Safari на iPhone, нажать «Поделиться» → «На экран “Домой”». При первом открытии Tuna может один раз показать страницу подтверждения с кнопкой «Посетить».

Туннель работает как пользовательская служба macOS `fitness`, запускается после входа в систему и не зависит от открытого терминала. Mac должен быть включён и не спать, Docker и контейнер приложения должны работать.

```bash
tuna service status --name=fitness
tuna service logs --name=fitness -n 100
tuna service restart --name=fitness
tuna service stop --name=fitness
tuna service start --name=fitness
```

Служба создана командой `tuna service install --name=fitness -- tuna http 18080 --subdomain=rosy-river-0106`. Это бесплатный постоянный поддомен, уже привязанный к аккаунту; произвольное имя на бесплатном тарифе недоступно.

## Облачная копия

`tools/cloud_sync.sh` добавляет в Git все изменения кода и папки `data`, создаёт коммит и отправляет его в приватный репозиторий `git@github.com:vsfomin/fitness.git`. На основном Mac команда запускается автоматически каждую минуту через LaunchAgent.

Проверить вручную:

```bash
./tools/cloud_sync.sh
git status --short
```

Перед запуском на другом ноутбуке нужно настроить его SSH-ключ в GitHub. Для переноса не нужно копировать Docker volume или экспортировать базу.

## Docker Hub

Образ приложения: `fomik2/fitness:latest`. В него входят только `gym.html`, адаптер хранилища и HTTP-сервер. Каталог `data`, исходная выгрузка `tools/db`, заметки и фотографии в образ не включаются.

```bash
docker build -t fomik2/fitness:latest .
docker push fomik2/fitness:latest
```

## Устройство

- `gym.html` — интерфейс, программа и алгоритмы прогрессии.
- `web-adapter.js` — совместимость с прежним Claude Artifact API; вне Claude использует HTTP API и Server-Sent Events.
- `server.js` — сервер на Node.js без внешних зависимостей, атомарная запись JSON и хранение JPEG.
- `data/db` — актуальные тренировки, настройки, вес тела, питание, заметки и метаданные фото.
- `data/assets` — фотографии.
- `tools/db` — исходная выгрузка из Claude для первого запуска, если `data/db` пуста.
- `compose.yml` — приложение на порту `18080` и необязательный контейнер туннеля.

Автоматический разбор скриншотов питания зависел от Claude и в автономной версии отключён. Ручной ввод БЖУ и все остальные разделы работают.
