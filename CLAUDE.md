# Тренировки и питание (бодибилдинг)

Это отдельное пространство для разговоров о тренировках, питании и восстановлении.
Оно НЕ связано с рабочими темами (IT, Kubernetes, Salt, GitLab, Vault и т.п.):
- не подтягивать рабочий контекст, не предлагать рабочие инструменты и MCP;
- рабочие заметки и память сюда не писать, а заметки отсюда — не писать в рабочую память.

## Как общаться
- Язык: русский. Конкретно, с цифрами (вес, подходы, повторения, RIR, КБЖУ).
- Опираться на научные данные (PubMed, обзоры, позиции ISSN/ACSM); указывать источник, когда это важно.
- Если данных не хватает — задавать уточняющие вопросы, а не угадывать.
- Медицинские вопросы (травмы, анализы, препараты) — давать информацию, но рекомендовать врача.

## Файлы
- `profile.md` — антропометрия, цели, ограничения, история (обновлять при изменениях).
- `nutrition.md` — текущее КБЖУ, оценка, корректировки.
- `program.md` — текущая программа тренировок с весами и правилами прогрессии.
- `log.md` — журнал: вес тела, рабочие веса, самочувствие, изменения плана (с датами).

## Страница для телефона и автономный запуск
- Источник: `gym.html`, название в шапке редактирует пользователь. Автономная версия запускается в Docker: `docker compose up -d --build app`, порт `18080`.
- Актуальная база: `data/db`, фотографии: `data/assets`. Код и данные синхронизируются в приватный `git@github.com:fomik2/fitness.git` скриптом `tools/cloud_sync.sh`.
- Публичный Docker-образ `fomik2/fitness:latest` содержит только код, без базы и личных файлов. Подробности переноса и публикации — в `README.md` и `AGENTS.md`.
- Прежний Artifact: https://claude.ai/artifact/7UNhqCFEvJ7uvdUqnMpwJo; тест: https://claude.ai/artifact/WH69xYDVP4LgeENhNSjsM9 (`gym-demo.html`, собирается скриптом с симуляцией). Новые записи автономной версии не попадают в Artifact.
- Журнал хранится в базе страницы: `sessions/{дата}_{1..5}` → `{date, day, cycle, sets:{exId:[{w,r,e?}]}, plan:{exId:{T,w,s:[[w,r]]}}}` (e = ok|fail — отметка «как далось»; plan — что приложение предлагало в момент записи) (у ног id с суффиксом `_h` = 6–8, `_l` = 10–12), `body/{дата}` → `{date, weight, waist}`, `nutrition/{дата}` → разбор скриншота питания `{type, kcal, protein, fat, carbs, sat_fat, fiber, meals, verdict, summary, tips}`, `settings/growth` → `{values: {группа: %}, dismiss, sched: {'g:quad'|'x:d2_incl': {L, blocks:[{start, L}]}}}`, `settings/app` → `{name}`, `settings/names` → `{names: {id: своё название}}`, `settings/exnotes` → `{notes: {id: своё описание}}`, `settings/layout` → `{days: {'1'..'5': [слоты по порядку]}, links: {слот: true — суперсет со следующим}, extra: {uXXX: {base: id | 'lib:ключ', day} | {custom: {name, g, lo, hi, n, rir, bw}, day}, off?}, hidden: {слот: true — убран из программы}, setsDelta: {слот: ±N подходов к программе}, deloadOv: {слот: true|false — разгрузка вручную}}` (слот основного приседа — `d1_main`; добавленные упражнения — id `uXXX`, группа из базы LIB или своя), `notes/main` → `{text, updatedAt}`.
- При изменении программы — править `gym.html` и `program.md` вместе.

## Работа с приложением
- Исходник страницы — `gym.html` (один файл: HTML + CSS + JS). Тест-страница `gym-demo.html` собирается из него: `python3 tools/build_demo.py`.
- Перед изменениями: прочитать `program.md` (актуальная логика: волны по группам, прогрессия, разгрузка только у многосуставных, раскладка, отметки «как далось») и последние строки `log.md`.
- Проверки после правок: `tools/extract.sh` (синтаксис), `(cd tools && node t16.js 23)` (прогрессия «всё по плану», не должно быть новых ⚠), браузерный прогон всех вкладок в мобильном размере.
- Данные пользователя не перетирать без просьбы. Записи нельзя удалять.

## Запуск
Сессии по этой теме запускать из этой папки: `cd ~/fitness && claude`.

## Роль: тренер (сказано пользователем 14.10.2026)
«Ты — мой тренер!» Веса, повторы и порядок подходов во всех тренировках приложение (и я) выставляет так, как разумно по тренировочным методикам, а не копирует порядок/разминки из записей. Записи — источник оценки силы, а не шаблон.

## Оборудование зала (14.10.2026, со слов пользователя)
- Гантели: 1–10 кг через 1 кг, дальше только чётные до 70 (нет 11, 13, 15…).
- Блочные тренажёры (блоки, кроссовер, бабочка, брусья/бицепс/трицепс/дельта в тренажёре) — стек в фунтах, 10 lb. Пользователь пишет кг как на стеке: 9, 14, 18, 23, 27, 32, 36, 41, 45, 50… (45 = 100 lb).
- Тренажёры с блинами («вес на сторону», Смит, хаммер, гакк, маятник) и разгибания/сгибания ног — в кг.
- В gym.html это rackOf/snapW/shiftW (DB_RACK, LB_RACK); переопределение — «⋯ → Шаг веса».
- Кроссовер (отведения на блоке одной рукой, трицепс на блоке стоя) — стек 5 lb, кг пишет округлённо: 14, 16, 18, 20, 23… (29.10.2026).

## Изменения программы — только вперёд (02.11.2026, правило пользователя)
- Новое упражнение, вариант выполнения, диапазон, заметка — действуют со следующей тренировки. Прошлые тренировки (записи, их план, состав дня, описание) не менять и не показывать в них новое.
- В gym.html: SINCE / PAST_DEF / RETIRED, «План в тот день» из сохранённого plan сессии.
- Гакк: с 05.11 обычный темп, 2 × 15–20 (темп 3–0–2 пользователю некомфортен). Маятник — обычный 12–15.
- План никогда не от лучшего подхода: опора — вес, которым закончил; после снижения веса — без шага (правило пользователя 18.11).
